# Rasphia plugins for coding agents

Rasphia (https://www.rasphia.com) finds and books local services and shops in India. This repository is the plugin for coding agents:
it installs the Rasphia skill and connects the Rasphia MCP server in one step.

For AI agents: the setup instructions are at https://www.rasphia.com/agent-setup.md

## Claude Code

    claude plugin marketplace add jjhbk/rasphia-plugins
    claude plugin install rasphia@rasphia

Then run `/reload-plugins`, and sign in with `/mcp` → **rasphia** → Authenticate.

## Codex

    codex plugin marketplace add https://github.com/jjhbk/rasphia-plugins.git
    codex plugin add rasphia@rasphia

Then sign in when Codex asks, or with `codex mcp login rasphia`.

Generated by scripts/build-agent-plugins.ts in the Rasphia app; don't edit by hand.
